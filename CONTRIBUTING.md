# Contributing

Thanks for helping improve Convert to USD.

## Before opening a pull request

1. Keep changes focused on a single bug fix or improvement.
2. Run `npm test`.
3. If you change the selection parser, add or update a test case in `currency.test.js`.
4. Test the extension by loading it unpacked in Chrome or Dia and using it on a normal webpage.

## Reporting bugs

Please include the browser and version, the selected text, what you expected, what happened, and any error shown by the extension service worker on `chrome://extensions`.

Never include passwords, payment details, access tokens, or private browsing data in an issue.
