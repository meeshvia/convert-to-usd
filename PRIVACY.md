# Privacy policy

Last updated: November 22, 2026

Convert to USD does not collect, store, sell, or share personal information.

When a user chooses **Convert to USD** from the browser context menu, the extension identifies the selected amount's currency locally. It sends only that three-letter currency code (for example, `EUR`) to Frankfurter's exchange-rate API over HTTPS and receives a USD exchange rate. It does not send the selected amount, page text, browsing history, account data, or any other page contents.

The extension does not use analytics, advertising, cookies, remote code, or third-party tracking. It does not persist conversion history.

Questions about this policy can be raised through this repository's issue tracker.
